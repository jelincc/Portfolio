광고 영상 제작은 전문 인력과 편집 도구, 시간이 필요한 작업이라 소상공인·마케터가 직접 만들기 어려웠습니다. 영상 제작 경험이 없는 사람도 광고 영상을 만들 수 있게 하려면, 편집이 아니라 "선택과 입력"만으로 완성되는 구조가 필요했습니다.

만약:

영상 제작을 템플릿 선택 → 이미지·텍스트 입력 → 확인 3단계로 단순화하면

Usability Testing

Planning → Design → Execution → Report 4단계로 UT를 설계하고 진행했습니다.

01 · Planning

사용자 테스트 계획서

  • VPLATE 서비스 UT Test 목적 및 대상 설정

  • 사용자 앱 기능 숙련도별 단계 정의
  • 사용자 태스크 분석
  • VPLATE 서비스 주요 기능 분석 및 태스크 추출
02 · Design

사용성 테스트 설계서

  • 단일/비교 테스트 설계, 질적/양적 결과 데이터 정의
  • 테스트 참가자 선정 · 참가자 수 결정
  • 조건에 부합하는 참가자 무작위 추출
  • 참여 안내/동의서 작성
  • 과업 선정 · 과업 분석, 순서, 지침 작성
  • 질문지 인터뷰 작성 · 사전/사후 설문서·인터뷰 항목 작성
03 · Execution

질적/양적 Raw data

  • 진행 시나리오 작성
  • 사전 테스트 · Pilot-test 시행 · 진행 스크립트 수정
  • 본 테스트 진행
  • 사용자 버벌·이벤트 관찰 사항 체크
04 · Report

사용성 테스트 결과 보고서

  • 개선 우선순위 분석

개선 항목내용
다중 씬 이미지같은 영상 내 이미지가 교체되는 경우 사용자 혼란을 방지하기 위해, 한 씬 내에서 슬라이드로 다음 이미지를 넣을 수 있도록 환경 개선
소스 입력 영역영상·이미지·텍스트 입력 시 아이콘 색상을 옅은색 → 뚜렷한 색으로 변경해 인지성 향상
페이지 이동한 씬 내 다음 소스로만 이동 가능했던 것을, 모든 씬을 슬라이드로 이동할 수 있도록 업데이트
네비게이션 바모든 소스가 입력됐을 때와 아닐 때를 시각적으로 차별화

Customizing 1 · 테마

영상 전체 테마 색상을 변경할 수 있는 UI 추가. 입력된 색을 그대로 보여줘 쉽게 인지하도록 함.

Customizing 2 · 폰트

제시된 폰트 중 원하는 폰트를 선택해 영상에 적용. 각 폰트는 기본 색상과 강조 색상으로 구분.

Customizing 3 · BGM

앱 내 제공 음원을 선택해 원하는 타이밍에 맞춰 적용. 재생 타이밍을 페이지 내에서 미리 볼 수 있음.
