Objective · Hypothesis

Ad videos finished by choosing, not editing

Making an ad video usually takes skilled people, editing tools, and time, which puts it well out of reach for small business owners and marketers trying to do it themselves. To let someone with zero video experience make an ad, the process couldn't be about editing at all; it needed to come down to nothing but choosing and filling in.

If:

Video creation could be boiled down to three steps: pick a template → add images and text → confirm,

Then:

Even a user with zero editing experience could finish an ad video in 5 minutes

Usability Testing

UT split by user experience level

01 · Planning

User Test Plan

  • Set the objective and target audience for VPLATE's UT
  • Define user groups and environment
  • Define proficiency tiers by app feature familiarity
  • Analyze user tasks
  • Analyze VPLATE's key features and extract tasks
02 · Design

Usability Test Design Doc

  • Design single/comparative tests, define qualitative/quantitative result data
  • Select test participants · determine participant count
  • Randomly sample participants who meet the criteria
  • Write participation guide/consent form
  • Select tasks · analyze tasks, define order and instructions
  • Write questionnaire/interview · write pre/post survey and interview items
03 · Execution

Qualitative/Quantitative Raw Data

  • Write the session script
  • Pilot test · run a pilot test · revise the session script
  • Run the main test
  • Record verbal and behavioral observations
04 · Report

  • Analyze qualitative/quantitative data · synthesize overall results

UT Test · Analysis

Comparing expected time against actual completion time, questions, and errors, by task

After identifying issues task by task, we focused our analysis on the areas causing the most trouble.

Expected time Actual time Questions asked Errors

▲ Combined graph for types A, B, and C. The dashed red zones mark the trouble spots where completion time and errors spiked well past expectations.

Task 1-2 Finding the account page after logging in: users got confused, since the filter button sits exactly where most other apps put user info
Task 4-1, 2, 3 Making a video in the template editor: users struggled to tell which scenes they had and hadn't filled in, and kept trying to swipe through every page like a slideshow
Task 6-3, 4 Finding and paying for the monthly plan: the words "monthly payment" and "Premium" didn't connect in users' heads (*"Subscribe" isn't a common term here)
Task 7-2 Making a video in the template editor: repetition helped users get used to the environment, but they kept making the same kinds of mistakes as before
Outcomes · App Improvements

We kept refining the editing environment based on interview insights

Task 4-1, 2, 3, 7-2 · Making a video in the template editor

ImprovementDetails
Multi-scene imagesTo prevent confusion when images get swapped within the same video, users can now add the next image as a slide within a single scene
Source input areaChanged icon colors from muted to bold when adding video, image, or text, improving recognizability
Page navigationPreviously you could only move to the next source within one scene, so we updated it so every scene can be reached by swiping
Navigation barVisually distinguished the state where all sources are filled in from when they aren't

Customizing 1 · Theme

Added a UI for changing the video's overall theme color. Shows the entered color exactly as-is, so it's easy to recognize.

Customizing 2 · Font

Pick a font from the presets and apply it to the video. Each font is distinguished by a base color and an accent color.

Customizing 3 · BGM

Choose from the app's built-in tracks and time it to fit. Playback timing can be previewed right on the page.

We identified the insights and pain points from the interviews and built the fixes directly into the design.
