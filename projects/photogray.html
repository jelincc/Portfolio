Overview

콜라보 하나에 며칠이 걸리던 운영을 어드민으로

포토부스 브랜드 콜라보를 진행할 때마다 프레임 등록, 매장 배포, 정산 등 여러 단계를 수작업으로 처리하고 있었습니다. 단계가 많고 담당자 의존도가 높아, 콜라보 하나를 준비하는 데 오랜 시간이 걸렸습니다.

대상

내부 운영팀, 콜라보 파트너 브랜드

문제

콜라보 준비·배포·정산을 수작업으로 처리, 사람에 의존하는 운영 구조

목표

운영 단계 자동화로 리드타임 단축, 인적 리소스 의존도 감소

Process · 협업 부서 인터뷰 기반

기존 프로세스의 문제점과 해결 방안

배포 완료관련 데이터 모니터링
01부스 관련 정보 분산
Painpoint기안·프레임·부스 시안이 그룹웨어·피그마·팀즈 등 여러 툴에 흩어져, 담당자가 전체 진행 상황을 파악하기 어려움.
Solution어드민에서 전 업무 프로세스를 통합해 정보를 일원화. 업무 혼선 감소와 인력 효율 향상으로 이어짐.
02테스트 시 잦은 옵션 변경
Painpoint부스 옵션값 설정·수정이 다수 발생할 때마다 담당자 간 커뮤니케이션 비용이 과다하게 들어감.
Solution담당자가 어드민에서 수정사항을 직접 반영할 수 있게 해, 테스트 효율을 높임.
03개발 의존 테스트
Painpoint부스·프레임 최종 테스트마다 개발팀 리소스가 필요해, 인적 리소스 소모와 일정 지연 위험이 컸음.
Solution개발자에 의존하지 않고도 테스트를 진행할 수 있는 구조로 바꿔 일정 지연을 방지.
Output

콜라보 관리 · 캠페인 운영을 하나의 어드민으로

프로젝트 진행 단계(요청중 → 디자인 진행중 → 테스트 진행중 → 배포 내역)에 맞춰 탭 메뉴를 구성하고, 각 단계별 화면 UX설계·디자인을 진행했습니다.

콜라보 관리

브랜드 콜라보 등록부터 프레임 배포, 매장별 노출 설정까지 단계별로 처리할 수 있는 관리 화면을 설계했습니다. 본사 부스에 먼저 데이터를 적용해 테스트·수정을 반복한 뒤 전국 부스에 배포하는 구조입니다.

운영 자동화 플로우

업무 단계를 최소 12단계로 표준화해, 전국 부스 배포까지 어드민 워크플로 안에서 처리할 수 있도록 재구성했습니다. 배포 시 프레임별 데이터가 집계되고, 필요하면 수정 후 재배포할 수 있는 구조로 만들었습니다.

디자인시스템

어드민 전용 컴포넌트(테이블, 필터, 상태 배지 등)를 새로 정의해 이후 다른 어드민 화면에도 재사용 가능하게 만들었습니다.
