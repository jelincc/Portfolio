Overview

고정된 이명음, 높은 중도 이탈률을 노치 테라피로 풀다

Objective

국내외 이명완화 서비스 시장 확대 · 활성 사용자 증대 · 노치 테라피를 통한 이명완화 효과 검증

Technology

사용자가 선택한 범위의 음역대만 삭제하는 특정 소음 제거 기술, 다양한 주파수 대역 음원 믹싱

Software

이명 종류·볼륨 선택으로 이명음 찾기, 간단한 조작으로 재생·믹싱, 약 20여 개 이명 테라피 음원 제공

Define

기존 컨트롤 앱의 3가지 문제와 대응 전략

하드웨어 제품 사용자 약 300여 명 설문과 리서치·내부 테스트·GA 데이터를 근거로 서비스 방향을 잡았습니다.

콘텐츠 부족 → 중도 이탈

문제: 기존 컨트롤 앱은 중도 이탈률이 높음

컨트롤 기능 대신 고객이 원하는 이명완화 기능을 소프트웨어에 탑재

높은 이명 빈도

문제: 난청 고객은 이명완화 기능을 매우 필요로 함

청력검사 기반 데이터 축적으로 맞춤형 서비스 제공, 이명 일기 기능으로 완화 정도 체크

고정된 이명음

문제: 제공되는 이명음이 대부분 고정돼 선택에 한계

이명 유형·음역대 선택으로 직접 이명음을 찾고, 테라피음을 예약·믹싱하는 부가 기능 제공

Process

약 50개 유사 서비스 분석 후 IA·프로토타입 설계

단계내용
ResearchSWOT 분석, 시장조사
Define서비스 목표 설정, 기능 확정
Plan화면 설계(Flow, 정책서), 기술 검토 및 확정
DesignMVP 기반 Prototyping 디자인
Beta Test1·2차 기획안 작성, 테스터 모집·선정, 1·2차 진행 및 결과 도출
Analysis임상 결과 분석

이명 커뮤니티 카페 매니저와 협력해 이명을 겪는 사용자를 테스터로 모집했고, 1:1 대응으로 구체적인 피드백을 수집했습니다.

Prototyping · 5개 핵심 화면

이명음 찾기(주파수·톤 타입 매칭) · 홈 화면(WAVE Filter™ 재생) · 테라피 목록 · 청취 이력(막대그래프) · 타이머 설정, MVP를 기반으로 기능 구현을 최우선해 테스트용 앱을 제작했습니다.
